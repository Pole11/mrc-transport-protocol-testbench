# MRC Transport Protocol Testbench

## Project Structure

- `include/`
    - `rocev2_config.hpp` Coyote requires this configuration file
    - `tests.hpp` contains the function definitions to test the modules
    - `util.hpp` header for `util.cpp`
- `src/`
    - `integration/`
        - `dut_mrc_transport_protocol.cpp` is the integration test of the top module of the transport protocol
    - `unit/`
        - `dut_*.cpp` one file per module devoted to unit test it
    - `main.cpp`
    - `util.cpp` contains some functions used by more than one module
- `run.log` (generated by running `make run`) contains the output of the last test run

## How to run

1. inside `Makefile` change the line `NETSTACK   := ../Coyote-mrc/hw/services/network/hls # change me` according to your Coyote directory
2. `make run` to run all the tests
